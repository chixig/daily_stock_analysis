# B10 隔夜赢家样本反推与有限拟合

状态：active，2026-09-16。用户明确提出先寻找收盘买、次日开盘卖的优秀样本，再反推规律与因子。本轮按此授权开展结果导向探索，不沿用B09停止价格因子探索的研究建议，也不恢复旧概率仓位方案。

## 冻结口径

- 继承B08逐笔台账、原始输入哈希、1000股、佣金最低5元、历史印花税/过户费、每边5bp滑点及20%股息税情景。行情截至2026-09-11；只用GitHub已有数据，所有计算与明细留GitHub。
- 主要探索区间2020年以来。优秀标签固定为净收益>=1%；0.5%、2%仅报告分布，不用于择优标签。同时列收益率前20与现金前20，避免股价水平影响现金排行。
- 分析前一交易日的价格/波动/量、截至买入日14:50的盘中路径，以及已知日历间隔，共24个归一化特征。不把当日最终收盘、高低、全日量或隔夜结果用于信号。
- 描述性对照：优秀vs其他、优秀vs<=-1%亏损；每个优秀样本在同年、同既有阶段取前20日波动率最近的3个非优秀样本，允许不同案例重复匹配，披露唯一对照数。此匹配不是因果识别。p和BH q仅探索描述。

## 两类可解释拟合

分类树寻找>=1%赢家，回归树预测净收益。均固定max_depth=2、min_samples_leaf=40、seed=601138；不网格搜索、不事后扩大深度。缺特征完整剔除并披露，不插值。

先全样本拟合，明确标记样本内；展示全部叶节点，分类选择优秀率最高且至少5个赢家的叶子，平局按净均值、数量、节点ID，回归选择净均值最高叶子。每条路径最多两个判断。分别报告未设经济门槛的最佳叶子与训练期均值/删5赢家均值/删5现金均为正的经济门槛。

再按2022—2026逐年回溯：训练只纳入年初前已完成卖出的2020年以来样本；每年规则由当时训练集重拟合，固定到该年末。分类/回归各一个候选，不根据测试结果选择。此历史已在前批观察，不称独立新样本或前瞻认证。

## 验证与反证

完整报告误选、召回、>=1%比例、<=-1%比例、净均值、现金、最差笔、删赢家、早近窗口及年度。单边滑点0/10/20bp压力与09:35成交代理、固定资金账户另列，不混同理论机会。负净收益日期的反向独立计费只登记镜像，不切主线。

校验输入哈希/B08现金、未来数据扰动、特征前缀不变、训练标签结束日期和前缀拟合结构一致。若优秀率提高但净均值仍负，判定为识别大幅波动而非可交易收益优势；若仅样本内好，则保留假设，不部署。

方法参考：[scikit-learn 1.5 decision trees](https://scikit-learn.org/1.5/modules/tree.html)。可解释树仍会过拟合，深度/叶样本数限制不能替代独立验证。
